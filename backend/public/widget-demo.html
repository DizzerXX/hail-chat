Telediant

This is a stand-in customer page — the chat bubble in the corner is the TDEChat widget.

Try it

Open the bubble and ask something the FAQ bot knows (e.g. “Bagaimana saya menetapkan semula kata laluan?” or “What are your operating hours?”), or type anything else to be escalated to the agent queue — then accept it from the agent dashboard and chat both ways in real time.

Embedding on your own site

<script src="https://YOUR-TDECHAT-HOST/widget.js"
        data-inbox="website"
        data-reverb-key="YOUR_REVERB_APP_KEY"
        data-ws-host="YOUR-TDECHAT-HOST"
        data-ws-port="8080"></script>
